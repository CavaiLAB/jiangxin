# 2026-11-20 迁移与发布裁定

本次裁定延续 [2026-11-19 的平台级编号](2026-11-19-platform.md)，适用于 Qian 的后续版本和 Kun 的首个合并版。

| 编号 | 产品负责人裁定 |
|---|---|
| P34 | Qian 的 8 个界面层包统一定版本。TypeScript 运行时与前端插件 SDK 各自定版本。 |
| P35 | Qian 的前端组件文档继续由现有组件文档站发布。每次生成定稿时，从前端仓库检出相应的发布标签。 |
| P36 | Kun 首个合并版的内核包通过 nuget.org 的可信发布（OIDC）发布。平台包发布到 CavaiLAB 的公开 GitHub Packages，并关联 `CavaiLAB/kun`。 |

版本与包源的使用说明见[协作约定](../07-governance.md)第 7 节。平台总览与组件文档站的分工见[仓库与归属](../05-repositories.md)第 4 节。
