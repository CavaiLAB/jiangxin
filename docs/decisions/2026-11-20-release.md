# 2026-11-20 迁移与发布裁定

本次裁定延续 [2026-11-19 的平台级编号](2026-11-19-platform.md)，适用于 Qian 的后续版本和 Kun 的首个合并版。

> 2026-11-26 补：各篇文档在这一天改过（[2026-11-26 平台级裁定](2026-11-26-platform.md) P87）。《仓库与归属》一篇已删除，本文里指向它的链接改指删除之前的版本，文字没有动。本文引用其他各篇时写的题目与节号是当时的，现在不一定对得上；各篇现在叫什么、旧内容现在在哪，见那份记录第 8 节。

| 编号 | 产品负责人裁定 |
|---|---|
| P34 | Qian 的 8 个界面层包统一定版本。TypeScript 运行时与前端插件 SDK 各自定版本。 |
| P35 | Qian 的前端组件文档继续由现有组件文档站发布。每次生成定稿时，从前端仓库检出相应的发布标签。 |
